# Modèles fiscaux officiels

Ce dossier contient les formulaires PDF vierges publiés par la DGFiP et utilisés
comme fonds pour le dossier de saisie contrôlé produit par ComptaOS.

- `2065-sd-2026.pdf` : formulaire 2065-SD, millésime 2026, CERFA 11084*28.
- `2033-sd-2026.pdf` : tableaux 2033-A-SD à 2033-G-SD, millésime 2026,
  CERFA 15948*08.

Sources : `impots.gouv.fr`. Ces fichiers ne constituent pas un dispositif de
télétransmission EDI-TDFC.
